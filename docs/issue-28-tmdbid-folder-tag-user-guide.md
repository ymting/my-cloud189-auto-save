# 任务文件夹追加 [tmdb-xxx] 标记 — 用户使用指南

**功能版本**：v3.0.5
**关联 Issue**：[#28](https://github.com/ymting/my-cloud189-auto-save/issues/28)

## 这是什么？

为已绑定 TMDB ID 的任务，在其云盘文件夹名末尾追加 `[tmdb-{id}]` 标记，方便 **Emby / Jellyfin / Plex** 等媒体管理工具通过 TMDB ID 直接精准匹配影视条目。

**示例**：
- 开启前：`狂飙 (2023)`
- 开启后：`狂飙 (2023)[tmdb-131887]`

## 解决什么问题？

**之前**：
1. Emby 扫描文件夹时，需要**靠标题二次匹配** TMDB
2. 如果标题翻译/别名/年份不同，**会匹配错**或匹配失败
3. 手动维护 Emby 库非常繁琐

**之后**：
1. 文件夹名末尾自带 TMDB ID
2. Emby 直接读取 `狂飙 (2023)[tmdb-131887]` → 准确匹配到 TMDB ID 131887
3. **零维护成本**

## 如何开启？

1. 进入 **系统设置** → **任务设置**
2. 找到 **"任务文件夹追加 [tmdb-xxx] 标记"** 选项
3. 勾选 ✅ 开启
4. 点击右上角 **保存设置** 按钮

**默认关闭**，不会影响现有 Emby 库。

## 开启后会发生什么？

| 任务类型 | 行为 |
|---------|------|
| **新创建的任务** | 自动在云盘文件夹名末尾追加 `[tmdb-{id}]` 标记 |
| **历史任务** | 不会自动迁移，需手动点击"迁移历史任务"按钮 |
| **已含标记的任务** | 不会重复追加（安全防御） |
| **未绑定 TMDB 的任务** | 不会追加标记 |

## 如何迁移历史任务？

⚠️ **重要**：开启开关**不会**自动迁移历史任务，避免误改 Emby 库。

### 操作步骤

1. 开启开关后，旁边的 **"迁移历史任务 →"** 按钮会变为可点击状态
2. 点击按钮 → 弹出预览窗口，列出**将迁移的任务**和**跳过的任务**
3. 确认无误后，点击 **"开始迁移"**
4. 进入**二次确认**：必须输入 **"确认迁移"** 四个字（防误操作）
5. 系统开始迁移，每个任务间隔 1 秒（避免触发云盘 API 限流）
6. 完成后显示**结果汇总**：成功 N 个，失败 M 个

### 迁移过程会修改什么？

- **云盘**：调用天翼云盘 `renameFolder` API 重命名文件夹
- **数据库**：更新任务的 `realFolderName` 字段
- **失败处理**：单个任务失败不影响其他任务

### 迁移失败的常见原因

| 错误 | 原因 | 解决方案 |
|------|------|----------|
| 云盘重命名失败 | 云盘 API 临时错误 | 重新点击迁移按钮（会跳过已成功的） |
| 任务不存在 | 任务被删除 | 忽略 |
| 权限不足 | 账号登录态过期 | 重新登录账号后重试 |

## 我可以反悔吗？

- **关闭开关**：新任务不再追加标记。**已迁移的任务不会自动还原**（避免误操作）
- **手动还原**：如果需要还原某个任务的文件夹名，请在"任务详情"里手动修改"目标保存目录"

## 安全性

- ✅ 默认关闭（不破坏现有 Emby 库）
- ✅ 二次确认（必须输入"确认迁移"才能执行）
- ✅ 预览功能（执行前先看将迁移什么）
- ✅ 失败隔离（单个任务失败不影响其他）
- ✅ 限流保护（1 秒/任务，避免触发云盘 API 限流）
- ✅ 操作日志（迁移过程写入 `logTaskEvent`，可在日志页面查看）

## 常见问题

### Q1: 开启后没看到效果？

请检查：
1. 是否点击了 **保存设置** 按钮？
2. 任务是否已绑定 TMDB？（`tmdbContent` 或 `tmdbId` 字段有值）
3. 任务名是否已含 `[tmdb-xxx]` 标记？（不会重复追加）

### Q2: 我已经有 500+ 任务了，能批量迁移吗？

可以。点击 **"迁移历史任务 →"** 按钮，系统会**逐个迁移**（1 秒/任务，约 8 分钟/500 任务）。

迁移过程支持后台运行，**可以关闭浏览器**——但**不建议**，因为失败的任务需要人工重试。

### Q3: 迁移过程中断网了怎么办？

已迁移的任务会保持新名称。未迁移的任务保持原名。重新点击迁移按钮即可继续（会跳过已含标记的）。

### Q4: [tmdb-xxx] 标记会影响其他工具吗？

**不会**。标记位于文件夹名**末尾**，Emby/Jellyfin/Plex 等工具都能正确识别并解析。

如果某些工具不支持，可以手动在 Emby 的"库设置"里配置忽略 `[tmdb-*]` 后缀。

### Q5: 我用的是电影任务，会受影响吗？

**会**。本功能**不区分电影/剧集**，只要任务有 TMDB ID 都会追加标记。

如果不想给电影任务加标记，目前的方案是：
- 关闭开关
- 或在 TMDB 绑定时不绑定电影任务

## 技术细节

### 涉及的数据库字段

- `task.realFolderName` - 云盘上的文件夹名

### 涉及的后端配置

- `data/config.json` → `task.appendTmdbIdToFolder`（布尔值）

### 涉及的 API

- `POST /api/tasks/migrate-folder-tmdbid` - 迁移接口（支持 dryRun 预览）
- `POST /api/settings` - 配置读写
- `GET /api/settings` - 配置读取

### 工具函数

`src/utils/folderNameUtils.js`：

```javascript
appendTmdbIdToFolderName(folderName, tmdbId)
// 返回 "原名[tmdb-{id}]" 或原名（已含标记时）
```
